# Dodge the Falling Blocks 🎮

A fast-paced 2D survival game built with **Python** and **PyQt5**. This project demonstrates advanced GUI implementation, custom event handling, and object-oriented programming.

## ✨ Key Features
* **Modular Architecture**: Separate modules for game physics, sound management, and UI screens.
* **Dynamic Gameplay**: Falling blocks with increasing difficulty and collision detection.
* **Abnormal States**: Special game modifiers like `reverse_floor`, `reverse_control`, and `random_blocks`.
* **Health System**: Integrated life management and damage processing.
* **High Score Tracking**: Persistent storage of your best scores.

## 🛠️ Installation & Usage
1. **Clone the repo**:
   ```bash
   git clone [https://github.com/AgSeyl/Dodge-Falling-Blocks.git](https://github.com/AgSeyl/Dodge-Falling-Blocks.git)

2. **Install PyQt5:**
   pip install PyQt5

3. **Run the game:**
   python main.py

## 🧠 Technical Highlights
* **Rendering**: Uses ```QPainter`` for smooth 2D graphics and glitch effects.
* **State Management**: Utilizes ```QStackedWidget``` for seamless transitions between menus and gameplay.
