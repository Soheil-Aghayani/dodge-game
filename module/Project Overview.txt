🎮 Project Overview: Dodge the Falling Blocks
📝 Project Name:
Dodge the Falling Blocks

📚 Technologies Used:
Language: Python 3.x

GUI Library: PyQt5 (or QtPy5 as a wrapper)

Optional Add-ons: QTimer (for motion), QPainter (for rendering), QtMultimedia (for sounds)

🎯 Objective:
Create a simple reflex-based game where the player must avoid falling blocks by moving left and right. The game becomes harder as time progresses.

🧩 Main Components:

Component	Description
Main Window	Game screen where all elements are drawn and updated
Player Object	A rectangle or image at the bottom that moves left/right with keyboard
Block Objects	Randomly generated blocks that fall from the top of the screen
Game Loop	Uses a timer to update block positions and check for collisions
Score System	Optional: Tracks how long the player survives or how many blocks dodged
Game Over	Stops the game loop and shows a "Game Over" message
📏 Game Flow:
Start game → player appears at the bottom.

Blocks fall from top at intervals.

Player moves using keyboard to dodge.

If a block hits the player → show Game Over.

(Optional) Restart or show score.
